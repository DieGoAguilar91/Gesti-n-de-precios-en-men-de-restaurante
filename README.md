# Gestión de precios en menú de restaurante 🍽️

## 📌 Descripción
Este proyecto corresponde a la **Fase 5 – Evaluación Final POA** de la asignatura **Fundamentos de Programación** en la UNAD.  
El objetivo es implementar un programa en **Python** que gestione los precios de un menú de restaurante aplicando una promoción específica.

## 🎯 Objetivo
- Representar el menú como una matriz con productos, categorías y precios base.
- Aplicar un **15% de descuento** a los productos que cumplan con:
  - Pertenecer a la **categoría objetivo** (ejemplo: *Plato Fuerte*).
  - Tener un precio base mayor a un **umbral definido** (ejemplo: 10,000).
- Mostrar cada producto con su nombre, categoría, precio base y precio final.

## 🛠️ Requisitos de desarrollo
- **Matriz:** Al menos 6 productos de diferentes categorías.
- **Módulo:** Función para calcular el precio final de un producto.
- **Lógica de negocio:**
  - Aplicar descuento si cumple condiciones.
  - Mantener precio base si no cumple.
- **Salida:** Mostrar resultados en formato tabular.
